# Varahi Billing Software

Presentation-ready restaurant POS and billing prototype.

## Prototype scope
- POS billing and cart
- Dine-in / Takeaway / Delivery order modes
- Table selection
- Category-based menu
- Discounts, tax and totals
- Payment modes
- Bill / receipt preview
- 58mm / 80mm thermal-style print layouts
- Kitchen order ticket (KOT) preview
- Simple dashboard and daily sales view
- Varahi-only branding and placeholder business contact details
